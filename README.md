## 🚀 Sobre o Projeto

O **WebDojo** é um ambiente prático para treinar automação de testes E2E com **Cypress**.

Ele simula um sistema real para prática de:

- Testes end-to-end
- Testes de API
- Integração com banco de dados
- Execução via Docker
- Estrutura profissional de projeto

---

## 🛠️ Tecnologias Utilizadas

- Git & GitHub 🌍
- Bash 💻

- Node.js 22+ 🟢
- npm / yarn 📦

## ⚙️ Como Executar o Projeto

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/Pxtrickvieira/webdojo.git
cd webdojo
```

### 2️⃣ Subir o ambiente com Docker

```bash
docker-compose up -d
```
### 3️⃣ Instalar dependências

```bash
cd web
npm install
```
### 4️⃣ Rodar o Cypress

```bash
npx cypress open
```
